# StudySpark — Smart Student Planner

## About the Project

StudySpark is a simple, browser-based student productivity application that helps students organize study tasks, track progress, and manage focused study sessions.

## Problem Statement

Students often struggle to manage assignments, deadlines, and study schedules across multiple subjects. StudySpark provides a centralized solution to make academic planning easier.

## Features

* Add and manage study tasks
* Mark tasks as completed
* Filter tasks by status
* Track study progress
* Use a focus timer
* Save tasks using browser Local Storage

## Technology Stack

* HTML5
* CSS3
* JavaScript
* Browser Local Storage

## How to Run

1. Download or clone this repository.
2. Open the `index.html` file in a web browser.
3. Start adding tasks and managing your study sessions.
